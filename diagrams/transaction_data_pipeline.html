Rules that keep it safe

One-way contractThe backend never reads its own scores through Silver External, so loops cannot form.
Idempotent scoringInput hash plus model and guideline versions decide whether a rescore happens.
No PII downstreamRedaction at ingestion for all channels. Recordings stay in blob storage.
Visible provenanceEvery metric states how it was produced, which version and how confident.
